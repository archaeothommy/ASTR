# Predict isotope provenance

Predicts Pb isotope provenance of a sample matrix using a XGBoost
trained list

## Usage

``` r
pb_iso_prov_predict(x, ...)

# S3 method for class 'ASTR'
pb_iso_prov_predict(x, model_list = NULL, top = 1, ...)
```

## Arguments

- x:

  Matrix of
  [`pb_iso_endmembers()`](https://archaeothommy.github.io/ASTR/reference/pb_iso_endmembers.md)
  object of pb isotope samples.

- ...:

  Additional parameters.

- model_list:

  Model list generated by
  [`pb_iso_train_data()`](https://archaeothommy.github.io/ASTR/reference/pb_iso_train_data.md).

- top:

  Number of highest probability values considered for final output,
  default value is `1`.

## Value

Data frame object or list of data frames.

## Examples

``` r
# Create an 'ASTR_Pbiso_ref_data' object
GlobaLID_ASTR_ref <- as_pbiso_ref_data(GlobaLID_ASTR,
                  names(GlobaLID_ASTR)[[2]],
                  min_groupsize = 5)

# Train machine learning model
if (FALSE) ml_model <- pb_iso_train_data(GlobaLID_ASTR_ref) # \dontrun{}

# Predict using a pre-trained model
if (FALSE) pb_iso_prov_predict(tel_dor, model_list = ml_model, .top = 1) # \dontrun{}
```
