# GlobaLID lead isotope database

ASTR object containing lead isotope data along with "Political
province/regions" as a grouping variable.

## Usage

``` r
GlobaLID_ASTR
```

## Format

ASTR object with 1 contextual and 3 Pb Isotope variables

- Political province/regions:

  Regional grouping of lead isotope data.

- 206Pb/204Pb:

  Lead isotope ratio of 206Pb/204Pb.

- 207Pb/204Pb:

  Lead isotope ratio of 207Pb/204Pb.

- 208Pb/204Pb:

  Lead isotope ratio of 208Pb/204Pb.
